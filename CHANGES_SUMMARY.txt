1. OVERVIEW OF CHANGES
--------------------------------------------------------------------------------
Implemented the complete end-to-end "Add Product" and "Products & GST Catalog" 
feature across both backend (Spring Boot) and frontend (React).

The system enables admin users to enter 4 primary fields:
  1. Product Name
  2. HSN Code
  3. Net Rate (Total Selling Rate including Tax)
  4. Tax (GST %)

From these inputs, the system automatically computes:
  - Rate (Excluded Tax / Base Price): Net Rate / (1 + GST% / 100)
  - Tax Amount: Net Rate - Rate
  - CGST Value (Central GST): Tax Amount / 2  (at GST% / 2)
  - SGST Value (State GST): Tax Amount / 2    (at GST% / 2)

FILE 1: backend/src/main/java/com/wholesale/orderapp/entity/Product.java
TYPE: Backend Java Entity (JPA / Hibernate)
ACTION: Created new file
--------------------------------------------------------------------------------
- Purpose:
  Represents the "products" table in the database.

- Database Table: "products"

- Fields:
  * id (Long): Primary key, auto-incremented.
  * name (String): Name of the product (e.g., "DAILY 100", "Basmati Rice 1kg").
  * hsnCode (String): Harmonized System of Nomenclature code (e.g., "33074100").
  * netRate (Double): Total selling price per unit inclusive of GST.
  * taxGst (Double): Applicable GST percentage (e.g., 5.0, 18.0).
  * rate (Double): Computed base rate before tax.
  * cgstPercent (Double): Central GST percentage (taxGst / 2).
  * sgstPercent (Double): State GST percentage (taxGst / 2).
  * cgstAmount (Double): Computed Central GST currency value.
  * sgstAmount (Double): Computed State GST currency value.
  * taxAmount (Double): Computed total GST currency value.

- Automatic Calculation Logic (@PrePersist & @PreUpdate):
  * Divisor: 1.0 + (taxGst / 100.0)
  * rate: Math.round((netRate / divisor) * 100.0) / 100.0
  * taxAmount: Math.round((netRate - rate) * 100.0) / 100.0
  * cgstPercent: taxGst / 2.0
  * sgstPercent: taxGst / 2.0
  * cgstAmount: Math.round((taxAmount / 2.0) * 100.0) / 100.0
  * sgstAmount: Math.round((taxAmount - cgstAmount) * 100.0) / 100.0

FILE 3: backend/src/main/java/com/wholesale/orderapp/controller/ProductController.java
TYPE: Spring Boot REST Controller
ACTION: Created new file
--------------------------------------------------------------------------------
- Base Route: /api/products
- Cross-Origin: @CrossOrigin(origins = "*") (enables React frontend access)

- REST Endpoints:
  * GET    /api/products       - Fetch list of all products with full GST breakdowns.
  * GET    /api/products/{id}  - Fetch a single product by ID.
  * POST   /api/products       - Create a new product. Triggers calculateTaxFields() 
                                 and saves to DB.
  * PUT    /api/products/{id}  - Update an existing product's name, HSN, Net Rate, 
                                 or GST%, recalculates fields and saves.
  * DELETE /api/products/{id}  - Delete a product from database by ID.
